# LiquidGlass

[EXPERIMENTAL] Gives iOS UI elements a real-time Metal-rendered Liquid Glass look.

## Features

- App Library icons and folders use a high-performance Metal renderer
- Home Screen folder icons retain the original effect
- Quick action toggles and passcode buttons are glassed
- Notifications on the Home Screen are also glass
- Dock, switches, and sliders use LiquidGlassKit
- For iOS 14-18, rootful, rootless, and roothide supported

## Compatibility

- iOS 14-18
- iphoneos-arm64 only
- Requires MobileSubstrate, Substitute, libhooker, or Ellekit
- Requires PreferenceLoader
